# FC Soluções Digitais

Página institucional de apresentação da **FC Soluções Digitais**, empresa especializada em soluções de presença digital para negócios. O site apresenta os serviços de criação de landing pages e lojas virtuais, explica os benefícios e o processo de atendimento e direciona os interessados ao contato pelo WhatsApp.

## Sobre o sistema

Este projeto é uma página estática responsiva desenvolvida para apresentar a empresa, seus serviços e diferenciais. A interface foi pensada para diferentes tamanhos de tela e inclui navegação por seções, apresentação de benefícios e dúvidas frequentes, chamadas para contato e recursos de privacidade e consentimento de cookies.

A página também conta com metadados para redes sociais, dados estruturados para mecanismos de busca e integração opcional com ferramentas de análise e publicidade, ativadas somente após o consentimento do visitante.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.8
- Google Fonts
- Schema.org / dados estruturados JSON-LD
- Integrações de consentimento e rastreamento de terceiros
- WhatsApp para atendimento e geração de contatos
